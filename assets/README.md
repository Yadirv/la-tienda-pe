# Assets de Iconos e Identidad Visual - La Tienda Pet

Esta carpeta centraliza todos los recursos visuales, iconos vectoriales y branding de la tienda.

## Estructura de Directorios

```
assets/
└── icons/
    ├── brand/
    │   ├── logo.svg        # Logo vectorial escalable con tipografía oficial
    │   ├── logo.png        # Logo de alta resolución en mapa de bits
    │   ├── favicon.svg     # Favicon vectorial
    │   └── favicon.png     # Favicon 64x64 para navegador
    ├── cart/
    │   └── cart.svg        # Icono minimalista de carrito de compras
    └── whatsapp/
        └── whatsapp.svg    # Icono oficial de WhatsApp para canal CX
```

## Paleta de Colores Oficial
- **Verde Principal (Brand Accent):** `#54B435` / `#6BD349`
- **Verde Oscuro (Brand Primary):** `#004E4A` / `#006B65`
- **Fondo:** `#F8F9FA` / Blanco
- **WhatsApp Green:** `#25D366`
